# INSANITY

선택지 기반 텍스트 로그라이크를 **만들고 플레이하는 플랫폼**입니다. 서울 2033처럼 매 판 인카운터가 다른 순서로 나오고, 죽으면 처음부터 다시 시작합니다.

- **플레이어**: 로그인하면 공개된 이야기 목록이 나오고, 골라서 플레이합니다. 진행은 계정에 저장됩니다.
- **제작자**: "제작자 화면"에서 내 이야기(초안/공개 중)를 만들고, 누르면 에디터로 편집합니다. 공개해야 플레이어 목록에 나옵니다.
- 사용자, 이야기, 플레이 저장은 **PostgreSQL**에 저장됩니다.

## 시작하기

필요한 것: Node.js 22 이상, PostgreSQL (아래 둘 중 하나)

```bash
npm install
cp .env.example .env          # Windows PowerShell: Copy-Item .env.example .env

# PostgreSQL이 없다면 Docker로 (DB 이름/계정이 .env.example과 같게 만들어짐)
docker compose up -d

npm run dev
```

- http://localhost:5173 — 회원가입 후 바로 쓸 수 있습니다. 같은 와이파이의 휴대폰에서는 `npm run dev`가 출력하는 Network 주소로 접속하세요.
- `npm run dev`는 API 서버(`server/`, 3000번)와 화면(Vite, 5173번)을 함께 띄웁니다. DB 테이블은 서버가 시작할 때 자동으로 만들어집니다.
- 이미 설치된 PostgreSQL을 쓰려면 Docker 대신 관리자 계정으로 아래를 한 번 실행하세요. `.env.example`과 같은 계정(`insanity`)과 DB(`insanity`, 테스트용 `insanity_test`)가 만들어집니다. 다른 계정/DB를 쓰려면 `.env`의 `DATABASE_URL`을 그 주소로 바꾸세요.

  ```bash
  psql -U postgres -h localhost -f server/local-setup.sql
  ```

  Windows에서 `psql`이 PATH에 없으면 전체 경로로 실행합니다 (PowerShell, 버전 번호는 설치한 것에 맞게):

  ```powershell
  & 'C:\Program Files\PostgreSQL\17\bin\psql.exe' -U postgres -h localhost -f server/local-setup.sql
  ```

### 예시 이야기 넣기

`content/` 폴더의 예시(흑포 기행, 인카운터 11개)를 내 계정의 이야기로 넣을 수 있습니다. 먼저 사이트에서 회원가입한 뒤:

```bash
npm run story:import -- --owner 내이메일@example.com --publish
```

### 배포

```bash
npm run build
npm start          # 서버 하나가 API와 화면을 모두 제공 (PORT, 기본 3000)
```

- HTTPS 뒤에서 서비스하는 것을 전제로 로그인 쿠키에 Secure가 붙습니다. HTTP로 시험할 때만 `.env`에 `COOKIE_SECURE=false`.
- 리버스 프록시(nginx 등) 뒤라면 `Host` 또는 `X-Forwarded-Host`를 원래 주소로 넘겨 주세요 (다른 사이트에서 온 요청을 막는 데 씁니다).

## 초안과 공개본

- 에디터의 **저장**은 *초안*만 바꿉니다. **공개하기**(또는 "수정 사항 공개")를 눌러야 플레이어가 보는 *공개본*이 초안으로 바뀝니다. 그래서 공개 중인 이야기를 고치는 동안에도 플레이어는 이전 공개본을 그대로 플레이합니다.
- 검증 오류(없는 페이지/아이템 참조 등)가 있으면 공개되지 않습니다.
- 같은 이야기를 두 탭/기기에서 편집하다가 한쪽이 먼저 저장하면, 다른 쪽 저장은 덮어쓰지 않고 거부됩니다 (새로고침 후 브라우저에 백업된 작업을 복구할 수 있음).
- 공개본이 바뀌어 진행 중이던 장면이 사라지면 그 플레이어의 저장은 "이어하기" 대신 새로 시작하게 됩니다.

## 게임 규칙

| 항목 | 내용 |
| --- | --- |
| 파라미터 | 화면 상단에 보이는 정보. 제작자가 원하는 만큼 추가합니다 (아래 표) |
| 아이템 | 개수가 있는 소지품 (보일지/이름은 제작자가 정함) |
| 능력 | 있거나 없는 특성 (보일지/이름은 제작자가 정함) |
| 플래그 | 플레이어에게 보이지 않는 숫자 변수. 이야기 진행 상태 기억용 |
| 저장 | 매 선택마다 계정(DB)에 자동 저장. 엔딩에 도달하면 저장이 지워짐 (영구 죽음) |

| 파라미터 종류 | 기본값 | 효과 / 조건 |
| --- | --- | --- |
| 수치 | 현재값, 최대값(있음/없음), 단위(있음/없음, 예: 원·%·kg). 막대 / 칸 / 숫자로 표시 (막대·칸은 최대값이 있을 때) | 현재값·최대값 증감. 최대값이 줄면 현재값도 그 이하로 깎임. 0 아래로는 내려가지 않음 |
| 상태 | 짧은 글 (예: 평온, 중독) | 다른 글로 바꾸기 / 같음·다름 |
| 캘린더 | 날짜 (연·월·일·요일 중 보여줄 것을 고름) | N일 넘기기, 날짜 정하기 / 이전·이후 비교 |

- 새 이야기는 기본으로 **체력**(칸, 3/3, 0이 되면 죽음)과 **정신력**(막대, 100/100, 0이 되면 광기, 낮아지면 화면 효과) 수치를 가집니다. 지우거나 바꿀 수 있습니다.
- 수치마다 "0이 되면 도달하는 엔딩"과 "낮아지면 화면이 어두워지고 흔들림"(시작 최대값의 40%·20% 이하)을 정할 수 있습니다. 여러 수치가 동시에 0이 되면 목록 위쪽이 먼저입니다.
- 파라미터마다 **상단 고정 / 펼치면 보임 / 숨김**을 정합니다. 숨긴 파라미터는 조건·효과에만 쓰이고 알림도 나오지 않습니다.

### 화면 (모바일 우선)

- 상단: ☰ 메뉴 · 파라미터. 제작자 설정에 따라 "상단 고정" 파라미터들 또는 제작자가 쓴 문구만 보입니다. 고정 파라미터는 두 줄까지 보이고, 넘치는 것은 겹치거나 잘려 보이지 않게 숨긴 뒤 **+N**으로 알려줍니다. 펼칠 것이 있으면 ▾가 붙어 누르면 모든 파라미터가 아래로 펼쳐집니다. 어떤 파라미터를 어디에(상단 고정 / 펼치면 보임 / 숨김) 어떤 순서로 둘지는 에디터에서 끌어서 정합니다.
- 가운데: 본문은 화면 위에서부터, 같은 인카운터의 다음 내용은 아래에 이어서 나옵니다. 선택지는 본문 바로 아래에 붙고, 본문이 길어 화면을 넘치면 선택지는 버튼 높이만큼만 하단에 남고 본문이 그 위에서 스크롤됩니다. 스크롤할 내용이 남은 쪽에는 페이드와 작은 화살표(누르면 스크롤)가 보입니다. 화면 전체는 스크롤되지 않습니다.
- 본문은 **한 글자씩 타이핑되듯** 나오고(문장 끝에서 잠깐 멈춤), 다 나온 뒤 선택지가 보입니다. 나오는 중에 화면을 누르거나 Space/Enter를 누르면 바로 모두 보입니다.
- 하단: **소지품 / 능력** 버튼 — 누르면 아래에서 시트가 올라옵니다. 내용이 바뀌면 점이 표시됩니다. 제작자가 끈 것은 버튼과 획득/상실 알림이 아예 나오지 않고, 이름과 비었을 때의 문구도 제작자가 정합니다.
- ☰ 메뉴(왼쪽에서 열림): 본문 글꼴 크기(4단계), 글자 나오는 속도(느리게/보통/빠르게/즉시), 화면 테마(이야기 설정/화이트/다크), 타이틀 화면으로, (테스트 플레이 중) 디버그 패널

### 테마

- 제작자는 팔레트에서 이야기의 **배경색과 글자색**을 고릅니다. 테두리·흐린 글자 같은 나머지 색은 두 색을 섞어 자동으로 만들고, 밝은 배경이면 강조색도 진하게 바뀝니다.
- **가변 색상**을 켜면 결과/페이지 효과에 "색 변경"이 생겨, 이야기 도중 원하는 시점에 배경/글자 색을 바꿀 수 있습니다 (천천히 바뀜). "이야기 기본 색"을 고르면 시작 색으로 돌아갑니다. 인카운터 설정의 **"인카운터가 시작될 때 색 바꾸기"**로 인카운터마다 시작 색을 정할 수도 있습니다 (시작 페이지의 진입 효과보다 먼저).
- 플레이어는 메뉴에서 **이야기 설정 / 화이트 / 다크** 중 하나를 고릅니다. 화이트·다크를 고르면 이야기 색과 가변 색상 대신 그 색으로 보입니다.

### 선택지

- **요구 조건**: 선택지 앞에 `[권총]`처럼 표시. 충족하면 초록, 아니면 빨강이고 고를 수 없음.
- **표시 조건**: 만족하지 않으면 선택지가 아예 안 보임 → "특정 능력이 있으면 생기는 선택지".
- **조건에 따른 결과 분기**: 요구 조건 없이도, 같은 선택지의 결과가 능력/아이템/수치에 따라 달라짐. 위에서부터 처음 맞는 분기가 선택되고, 마지막 "그 외의 경우"가 기본값.
- **확률 결과**: 한 분기 안에 결과를 여러 개 두면 가중치대로 무작위.
- **조건부 본문**: 조건에 따라 본문 자체가 바뀜. 여러 개를 둘 수 있고 위에서부터 처음 맞는 것이 기본 본문 대신 나옴.
- **추가 문단**: 조건을 만족하면 본문 뒤에 덧붙는 서술 (만족하는 것 모두).
- 선택지가 전부 빨간색이라 고를 게 없으면 "어쩔 수 없다 (계속)" 버튼이 나와 막히지 않습니다.

## 출현 규칙 (선후관계)

인카운터마다 출현 방식을 정합니다.

| 방식 | 설명 | 용도 |
| --- | --- | --- |
| 랜덤 | 조건을 만족하면 랜덤 풀에 들어가 가중치에 따라 뽑힘 | 대부분의 사건 |
| 후속 전용 | 랜덤으로는 안 나오고, 다른 인카운터 결과의 **인카운터 예약** 효과로만 등장 | 선택에 따라 이어지는 사건 |
| 고정 순번 | n번째 인카운터로 등장 | 프롤로그, 피날레 |

랜덤/고정 인카운터에는 추가로:

- **선행 인카운터 + 간격**: A를 겪은 뒤에만 등장. "사이에 최소 a ~ 최대 b개"는 A와 이 인카운터 사이에 끼어드는 다른 인카운터 수. 최대값에 도달하면 강제로 등장.
- **등장 구간**: n번째 ~ m번째 인카운터 사이에서만 (초반/후반 전용 사건).
- **추가 출현 조건**: 아이템/능력/플래그/수치/다른 인카운터를 겪었는지.
- **반복**: 기본은 한 판에 한 번. 반복 가능하게 하고 재등장 간격을 줄 수 있음.

자주 쓰는 패턴:

| 원하는 것 | 설정 |
| --- | --- |
| 아무 때나 나오는 사건 | 랜덤, 조건 없음 |
| A 바로 다음에 반드시 B | B의 선행 인카운터 = A, 간격 0~0 (또는 A 결과에 "B 예약, 0개 뒤") |
| A 다음에 순서대로 나오지만 사이에 랜덤 사건 2~5개 | B의 선행 = A, 간격 2~5 |
| A에서 특정 선택을 했을 때만 이어짐 | B를 후속 전용으로 두고, A의 그 결과에만 "B 예약" 효과 |
| A에서 한 선택을 나중에 기억 | A 결과에서 플래그 설정 → B의 출현 조건/분기에서 플래그 검사 |
| A와 B 중 하나만 | B의 출현 조건에 "A 겪지 않음" (반대도) |

다음 인카운터 선택 우선순위는 **예약 → 고정 순번 → 강제(최대 간격 도달) → 랜덤**입니다.
출현 가능한 인카운터가 하나도 없으면 "정적" 엔딩이 나오므로, 반복 가능한 채움용 인카운터를 몇 개 두는 것을 권장합니다.

- **저장** (Ctrl+S): 서버에 초안으로 저장합니다. 저장 전 작업은 브라우저에 자동 백업되어, 창을 닫아도 다음에 복구할 수 있습니다.
- **공개하기**: 저장한 뒤 초안을 공개본으로 만듭니다 (위 "초안과 공개본").
- **되돌리기/다시** (Ctrl+Z / Ctrl+Shift+Z).
- **▶ 테스트 플레이**: 저장하지 않은 내용으로 새 탭에서 실행합니다. 테스트 탭이 열려 있으면 에디터에서 고친 내용이 바로 반영됩니다. 테스트 화면의 디버그 패널(`` ` `` 키)에서 파라미터/아이템/능력/플래그를 바꾸거나, 각 인카운터가 지금 왜 나올 수 없는지 확인하고 바로 시작할 수 있습니다.
- 아이템/능력/플래그/인카운터/엔딩 선택 칸의 맨 아래 **"＋ 새 … 만들기"**로 작업 도중 바로 만들 수 있습니다.
- 게임 단축키(데스크톱): 숫자 1~9 = 선택지, Space/Enter = 계속, Esc = 메뉴 닫기.

## 글자 서식과 효과

본문, 조건부 본문, 추가 문단, 선택지, 결과, 엔딩, 도입부에 쓸 수 있습니다. 아래에 미리보기가 보입니다.

- **글자를 드래그해 고르면** 그 옆(아래쪽이 모자라면 위쪽)에 서식 메뉴가 뜹니다. 기본 · 색 · 특수 효과 순으로 나열되고, 누를 때마다 켜지거나 꺼지며 메뉴는 닫히지 않습니다. 이미 걸린 서식에는 ✓가 붙고, 다시 누르면 해제됩니다. 같은 효과의 다른 값(떨림 → 떨림 강하게, 다른 색)을 누르면 값만 바뀝니다.
- **`[shake]`나 `[/shake]` 같은 표기를 누르면** 그 서식이 걸린 곳이 강조되고, 서식 삭제(글자는 남김) / 닫기 메뉴가 뜹니다.
- 입력칸 위의 도구 모음에도 굵게 · 기울임 · 색 ▾ · 특수 효과 ▾ · 서식 지우기가 있습니다.

| 표기 | 효과 |
| --- | --- |
| `**굵게**`, `*기울임*` | 굵게 / 기울임 (`[b]`, `[i]`로도 씀) |
| `[color=blood]…[/color]` | 색: `blood` 핏빛, `abyss` 심연의 녹색, `void` 보랏빛, `pale` 창백함, `gold` 빛바랜 금색, 또는 `#88ccaa` |
| `[faint]…[/faint]` | 희미하게 (속삭임, 환청) |
| `[shake]…[/shake]`, `[shake=strong]…[/shake]` | 짧게 가만히 있다가 자주, 글자마다 부르르 떨림 |
| `[flicker]…[/flicker]`, `[flicker=strong]…[/flicker]` | 고장 난 전등처럼 불규칙하게 깜빡임 (글마다 주기가 다름) |

- 서식은 한 문단(줄) 안에서만 적용됩니다. 여러 줄을 선택하고 서식을 고르면 줄마다 따로 감쌉니다.
- 짝이 맞지 않거나 모르는 태그는 글자 그대로 보이고, 검증 탭에 경고가 뜹니다.
- 기호를 그대로 쓰려면 `\[`, `\*`, `\\`.
- 예시: `content/encounters/mirror.json` (금 간 거울)

### 새 효과 추가하기

`src/markup/registry.tsx`의 `TEXT_EFFECTS`에 항목 하나를 추가하면 에디터 도구 모음/선택 메뉴, 게임 화면, 검증에 자동으로 반영됩니다.

```tsx
{
  tag: 'glow',                 // [glow]…[/glow]
  label: '빛남',               // 에디터 메뉴 이름
  description: '은은하게 빛나는 글자',
  group: 'special',            // 에디터 메뉴의 분류: basic(기본) / color(색) / special(특수 효과)
  params: [{ value: '', label: '보통' }, { value: 'strong', label: '강하게' }], // 선택 (값이 없으면 생략)
  // render를 생략하면 <span class="fx-glow fx-glow--strong">으로 감싸므로 markup.css에 CSS만 추가
  // 글자별 애니메이션처럼 직접 그려야 하면 render: (children, { param, seed }) => … (shake 참고)
}
```

## 이야기 JSON 형식

```
content/
  game.json                 메타, 시작 상태, 파라미터, 화면 설정(ui), 테마, 아이템/능력/플래그/엔딩 정의, 인카운터 목록 순서
  encounters/<id>.json      인카운터 하나당 파일 하나
```

에디터 없이 JSON을 직접 써도 됩니다. 빠진 필드는 기본값으로 채워지고, 아래처럼 줄여 쓸 수 있습니다.

```jsonc
{
  "id": "dark_alley",                         // 영문/숫자/_/- (파일 이름)
  "title": "어두운 골목",
  "spawn": { "mode": "random", "weight": 10, "minTurn": 3 },
  "nodes": [
    {
      "id": "start",
      "text": "골목 끝에서 무언가 젖은 소리를 내며 [shake]움직인다[/shake].",  // 기본 본문
      "variants": [                                                  // 조건부 본문 (처음 맞는 것이 대신 나옴)
        { "condition": [{ "type": "stat", "id": "sanity", "op": "<", "value": 30 }], "text": "골목 끝에서 [color=blood]네가[/color] 너를 부른다." }
      ],
      "extraTexts": [                                                // 추가 문단 (맞는 것 모두 덧붙음)
        { "condition": [{ "type": "trait", "id": "forbidden_lore" }], "text": "[faint]저것의 이름을 당신은 알고 있다.[/faint]" }
      ],
      "choices": [
        {
          "text": "총을 쏜다",
          "require": [{ "type": "item", "id": "pistol" }],          // 조건 배열 = 모두 만족
          "outcomes": [{ "text": "총성이 울렸다.", "effects": [{ "type": "stat", "id": "sanity", "value": -3 }, { "type": "date", "id": "day", "days": 1 }] }]
        },
        {
          "text": "주문을 왼다",
          "showIf": [{ "type": "trait", "id": "forbidden_lore" }],  // 능력이 있어야 보임
          "outcomes": [{ "text": "그것이 물러났다." }]
        },
        {
          "text": "다가간다",
          "branches": [                                              // 같은 선택지, 능력에 따라 다른 결과
            { "condition": [{ "type": "trait", "id": "iron_will" }], "outcomes": [{ "text": "버텼다." }] },
            {
              "condition": null,
              "outcomes": [                                          // 확률 결과 (가중치 3:1)
                { "weight": 3, "text": "눈이 마주쳤다.", "effects": [{ "type": "stat", "id": "sanity", "field": "max", "value": -5 }] },
                { "weight": 1, "text": "물렸다.", "effects": [{ "type": "stat", "id": "hp", "value": -1 }, { "type": "text", "id": "status", "value": "감염" }], "next": "bitten" }
              ]
            }
          ]
        }
      ]
    },
    { "id": "bitten", "text": "상처가 이상하게 차갑다.", "choices": [] }
  ]
}
```

| 조건 `type` | 필드 |
| --- | --- |
| `item` | `id`, `op`(기본 `>=`), `value`(기본 1) |
| `trait` | `id`, `has`(기본 true) |
| `flag` | `id`, `op`, `value` |
| `stat` | `id`(수치 파라미터), `field`(`value` 현재값(기본) / `max` 최대값), `op`, `value` |
| `text` | `id`(상태 파라미터), `op`(`==`/`!=`), `value` |
| `date` | `id`(캘린더 파라미터), `op`, `value`(`YYYY-MM-DD`) |
| `turn` | `op`, `value` — 현재 몇 번째 인카운터인지 |
| `seen` | `encounterId`, `has` — 이번 판에서 겪었는지 |
| `all` / `any` | `items`: 조건 목록 (모두 / 하나라도) |

| 효과 `type` | 필드 |
| --- | --- |
| `stat` | `id`, `field`(`value`/`max`), `value`, `valueMax`(있으면 value~valueMax 무작위) |
| `text` | `id`, `value`(바꿀 글) |
| `date` | `id`, `mode`(`add` N일 넘기기(기본) / `set` 날짜 정하기), `days`, `date` |
| `theme` | `background`, `text`(`#rrggbb`, `null` = 이야기 기본 색) — 테마의 가변 색상을 켰을 때만 |
| `item` | `id`, `value`(음수 = 잃음) |
| `trait` | `id`, `has`(false = 상실) |
| `flag` | `id`, `mode`(`set`/`add`), `value` |
| `queue` | `encounterId`, `delay`(0 = 바로 다음) |
| `ending` | `endingId` |

예전 형식(`"stat": "maxSanity"`, `start.hp` 등)도 읽을 수 있고, `npm run content`를 돌리면 지금 형식으로 정리됩니다.

`game.json`의 화면 관련 필드:

```jsonc
{
  "params": [
    { "kind": "stat", "id": "hp", "name": "체력", "show": "pinned", "value": 3, "max": 3, "unit": null, "display": "cells", "zeroEnding": "death", "mood": false },
    { "kind": "text", "id": "status", "name": "상태", "show": "panel", "value": "평온" },
    { "kind": "date", "id": "day", "name": "날짜", "show": "pinned", "value": "1931-12-01", "parts": { "year": false, "month": true, "day": true, "weekday": true } }
  ],
  "ui": {
    "hud": { "summary": "pinned", "text": "상태 보기" },   // summary: pinned(상단 고정 파라미터) / text(문구만)
    "items": { "show": true, "label": "소지품", "empty": "아무것도 가지고 있지 않다." },
    "traits": { "show": false, "label": "능력", "empty": "" }
  },
  "theme": { "background": "#0b0d0c", "text": "#d6d2c4", "variable": true }
}
```

`show`: `pinned`(상단 고정) / `panel`(펼치면 보임) / `hidden`(숨김). `display`: `bar` / `cells` / `number`. `parts`: 날짜에서 보여줄 연/월/일/요일 (위 예는 "12월 1일 (화)").

`startColors`: `{ background, text }` — 인카운터가 시작될 때 바꿀 색 (가변 색상, `null` = 이야기 기본 색). 없으면 그대로.

`spawn` 필드: `mode`(`random`/`triggered`/`fixed`), `weight`, `repeatable`, `cooldown`, `minTurn`, `maxTurn`, `fixedTurn`, `after: [{ encounterId, minGap, maxGap }]`, `condition`.
